🏭 About the Project

StockWise – Inventory Management System is a desktop application developed using Python, Tkinter, and SQLite.

It provides a simple interface for managing warehouse product records, including product names, prices, and quantities.

The application helps users maintain organized inventory information and perform essential product management operations efficiently.

⚙️ Key Features

Feature| Description
➕ Add Products| Add new products to the inventory
📋 View Products| Display all available product records
🔍 Search Products| Find products easily
✏️ Update Products| Modify existing product information
🗑️ Delete Products| Remove unwanted product records
🧹 Clear Fields| Reset input fields
✅ Input Validation| Validate product prices and quantities
🛡️ Data Validation| Prevent negative prices and quantities
📊 Excel Export| Export product information to Excel

🏬 Warehouse Operations

The system focuses on three essential inventory management activities:

- Product Management: Maintain product names, prices, and quantities.
- Stock Information: Keep product quantity information organized.
- Inventory Records: Export product data into Excel for further use.

🚀 Installation & Setup

Follow these steps to run the project on your computer.

1. Install Python

Download and install Python from:

https://www.python.org/downloads/

2. Clone the Repository

git clone https://github.com/saaqibmohiddin/Inventory-Management.git

3. Open the Project

Open the downloaded project folder in Visual Studio Code.

4. Install Dependencies

pip install openpyxl

5. Run the Application

python gui_new.py
